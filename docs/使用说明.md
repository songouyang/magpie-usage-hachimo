# Magpie 用量 {version} 使用说明

下载同一 Release 的 `magpie-usage-hachimo-{version}.hachiapp` 和 `magpie-collector-{version}.zip`。要求 macOS、Python 3.9+、运行中的 Magpie、支持 `petui-python-v1` 的 Pet Manager，以及兼容的 USB 设备。

1. 保持本机 Magpie 运行，默认地址 `http://127.0.0.1:3425`。
2. 解压采集器 ZIP，在解压出的 `collector` 目录执行 `python3 -m magpie_usage`，或双击 `start-collector.command`。启动后生成 `data/magpie-usage.txt`，每 15 秒采集一次。
3. 在 Pet Manager「组件中心 → 导入组件」选择 `.hachiapp`，打开「我的组件」中的「Magpie 用量」。
4. 在详情的「Python 数据插件」选择上述 `magpie-usage.txt` 并授权。插件每 30 秒读取一次，等待数据可用。
5. 连接设备 USB，点击「保存并同步」，等待安装完成后在设备打开组件。持续保持采集器和 Pet Manager 运行。

默认 SW1／摇杆向左为上一页，SW2／摇杆向右为下一页。可点总览、请求、会话、缓存标签；提示跟随实际绑定，退出跟随设备全局设置。升级保持同一组件 ID，需要重新授权插件并保存同步。

未授权或文件无效时显示等待占位，翻页仍可用。缺失指标显示「—」，真实零值保留。采集失败保留上次成功数据和时间，超过 60 秒显示过期，恢复后自动更新。

停止采集器用 Control-C；不要重复启动同一采集器，不提供开机自启。自定义文件路径可用 `--feed-file /absolute/path/magpie-usage.txt`，随后选择该文件授权。排查采集问题可执行 `python3 -m magpie_usage --local-only --once`，或用 `--output ./snapshot.json` 输出诊断；详细参数见 ZIP 内 README。

不要用编辑器保存、移动或复制覆盖正在授权的数据文件。采集器通过固定文件身份原位更新；文件替换后须重启采集器并重新授权。实时数据、缓存和诊断可能包含个人用量，不随包分享。

将 `SHA256SUMS.txt` 与三个附件放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt` 校验下载文件。当前设备验证范围和限制见仓库的 `docs/verification.md`；安装完成不代表实体按键、触点和 LCD 观感均已测试。
